⚠️ Troubleshooting

If something doesn't work:

  1. Check XAMPP: Apache and MySQL must be running
  2. Run migration: migration_add_company_sector.php
  3. Clear browser cache (Ctrl + Shift + Delete)
  4. Check error log: C:\xampp\apache\logs\error.log
  5. Open browser console (F12) for JavaScript errors
